# 商店上架清单（你需要介入的部分）

完整文案见 [LISTING.md](./LISTING.md)。下列为**必须你本人完成**的事项：

## 必须补充

1. **联系邮箱**  
   - 填入：`docs/privacy.md`、`docs/privacy.html`、商店后台「支持邮箱」  
   - 当前文案中已标：`【需你补充：对外联系邮箱】`

2. **隐私政策公网 URL**  
   - 推荐启用 GitHub Pages，发布 `docs/privacy.html`  
   - 或托管到你自己的域名  
   - 商店后台「隐私权政策」栏粘贴最终 HTTPS 链接

3. **商店截图（至少 1 张，建议 3～5 张）**  
   - 放到 `store/screenshots/`  
   - 要求见该目录 README

4. **开发者账号**  
   - Chrome：付费注册开发者  
   - Edge：Partner Center 注册  
   - 完成身份/支付等后台必填项

5. **类目 / 可见性 / 年龄分级**  
   - 在后台下拉框中确认最终选项（文案里已给建议）

## 可选补充

- 商店宣传大图、小图  
- 英文描述（LISTING.md 已提供草稿）  
- 开发者展示名是否改用真名/工作室名

## 已代为准备（一般不用你改）

- 扩展包：`dist/bilibili-name-history-0.0.1.zip`
- 名称、简介、长描述、单项用途、权限理由
- 隐私政策正文（缺邮箱）
- MIT LICENSE、仓库免责声明
