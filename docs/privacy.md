# 隐私政策 · B站曾用名

**生效日期：** 2026-09-26  
**适用产品：** 浏览器扩展「B站曾用名」（Chrome / Edge，Manifest V3）  
**开源仓库：** https://github.com/JUST-Limbo/bilibili-name-history

本扩展**仅供学习与技术研究**。使用前请阅读并同意本政策及仓库免责声明。

---

## 我们收集什么数据

本扩展在你的浏览器**本地**处理与存储以下信息（默认不上传到开发者自有服务器）：

| 数据类型 | 用途 |
|----------|------|
| B 站用户 mid（UID）与昵称快照 | 记录昵称变化，展示「曾用名」 |
| 你自己的 mid | 避免把自己记入备份库 |
| 扩展设置（同步速度、自动同步开关等） | 保存你的偏好 |
| 导入/导出的备份 JSON | 仅在你主动操作时读写本地文件 |

## 数据如何获取

- **页面 DOM**：在 `space.bilibili.com`、`www.bilibili.com` 等页面读取可见的 UP 链接与昵称文案。
- **可选 API**：若你主动使用「API 同步」或将自动同步设为 API 方式，扩展会向 `api.bilibili.com` 请求关注列表等相关接口（使用你浏览器已有的登录态 Cookie）。
- **Cookie**：扩展不单独「窃取」Cookie；请求 B 站接口时由浏览器按站点规则携带登录态。

## 数据存储与传输

- 昵称历史与设置保存在浏览器扩展本地存储（如 `chrome.storage` / IndexedDB）。
- **开发者不运营用于收集上述数据的后端**；不会把你的关注列表或昵称历史主动发送到第三方分析服务。
- 当你使用 API 同步时，数据仅在你的浏览器与 `bilibili.com` / `api.bilibili.com` 之间传输，遵循 B 站自身的隐私与服务条款。

## 权限说明（摘要）

| 权限 / 主机权限 | 原因 |
|-----------------|------|
| `storage` | 本地保存昵称历史与设置 |
| `offscreen` | 在后台标签节流时驱动 DOM 翻页扫描 |
| `scripting` | 自动同步时向关注页注入必要的页面可见性辅助脚本 |
| `https://space.bilibili.com/*` | 空间页 / 关注列表 DOM 收集与展示 |
| `https://www.bilibili.com/*` | 视频等页面 DOM 收集与展示 |
| `https://api.bilibili.com/*` | **可选** API 同步关注列表 |

## 数据删除

- 可在扩展 Popup 中使用「清空本地备份」删除本机昵称历史。
- 卸载扩展后，浏览器通常会清除该扩展的本地数据。
- 导出的 JSON 备份文件由你自行保管与删除。

## 第三方服务

- 本扩展功能依赖哔哩哔哩（bilibili）网站与接口；该等服务适用其官方隐私政策与用户协议。
- 本扩展为**非官方**第三方工具，与哔哩哔哩公司无关。

## 儿童隐私

本扩展面向一般用户，不以儿童为对象收集数据。
